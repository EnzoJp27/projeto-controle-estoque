# Sistema de Controle de Estoque

Projeto pessoal de nível iniciante desenvolvido em C# para praticar lógica de programação e conceitos básicos de desenvolvimento back-end.

## Funcionalidades
- Cadastrar produtos com nome e quantidade inicial.
- Listar produtos cadastrados.
- Registrar entradas e saídas de estoque.
- Impedir uma saída maior que a quantidade disponível.
- Identificar produtos com cinco unidades ou menos.
- Validar entradas numéricas.

## Tecnologias
- C#
- .NET 8
- Aplicação de console

## Como executar
1. Instale o .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
dotnet run
```

## Observação
Este é um projeto de estudo. Os dados ficam armazenados apenas durante a execução e são apagados quando o programa é encerrado. Uma evolução futura seria salvar os dados em um banco de dados, criar testes automatizados e disponibilizar uma API.
